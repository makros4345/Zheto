# Sites: website previews for local businesses

Demo websites made to pitch to small businesses in Ukraine.
Each preview is a single `index.html` file: open it in a browser or upload the folder to Netlify Drop / GitHub Pages.

| Folder | Business | City | Style |
|---|---|---|---|
| `kremova-preview/` | KREMÓVA, pastry shop | Kyiv | Pastel, "build your macaron box" |
| `zheto-preview/` | Жето, antique cafe | Odesa | Dark green & gold, events calendar |
| `zavarkin-preview/` | Пан Заваркін та син, museum-cafe | Vinnytsia | Old shop label, live antique clock |
| `demo-bakery/` | Golden Crust (fictional) | — | Portfolio sample |

Each business folder also has `MESSAGE.md` (outreach message in Ukrainian + English) and screenshots.

## Leads
- `kyiv-leads.csv`, `kyiv-leads-2.csv`: Kyiv businesses checked for websites
- `ukraine-leads.csv`: best leads across 15 Ukrainian cities
- `PLAYBOOK.md`: how to find clients, price and deliver

Note: yellow-highlighted placeholders (phone, hours, prices, photos) must be filled with the business's real information before launch.
