# Кофейня «ЖеТто» (Одесса) — сайт

Статический одностраничный сайт кофейни «ЖеТто», ул. Гаванная, 2, Одесса.
Язык — русский, валюта — гривна (₴).

## Как открыть

Вариант 1 — просто открыть файл:
- дважды кликните `index.html` (откроется в браузере).

Вариант 2 — локальный сервер (удобнее, карта и шрифты работают надёжнее):

```bash
cd zheto-site
python3 -m http.server 8000
```

Затем откройте в браузере: http://localhost:8000

## Структура

- `index.html` — разметка: прелоадер-жетон, герой, «Почему к нам приходят», «О нас», «День в ЖеТто», меню, «Кофейный оракул», галерея, бронь, контакты и карта, подвал.
- `css/style.css` — стили, «кофейная» палитра, анимации, адаптив под мобильные.
- `js/main.js` — вся интерактивность (без библиотек).

## Интерактивные функции

- **Прелоадер** — вращающийся латунный жетон «ЖеТто».
- **Вечерний режим** (кнопка со свечой) — страница темнеет, курсор работает как подсвечник. Выбор запоминается.
- **Пластинка** (кнопка слева внизу) — небольшой вальс, синтезируется в браузере (WebAudio), с треском винила. Включается только по клику.
- **«День в ЖеТто»** — ползунок времени: меняется небо над силуэтом города, солнце/луна, окна загораются ночью; карточка показывает, открыто ли в это время, и что посоветовать. Стартует с текущего времени в Одессе.
- **Меню** — табы, поиск по всему меню с подсветкой, кнопка «+» у каждой позиции.
- **Корзина заказа** — считает сумму в ₴, можно менять количество; сохраняется в браузере. Ничего никуда не отправляет — список показывают официанту или звонят.
- **«Кофейный оракул»** — 3 вопроса → пара «напиток + десерт» из меню, можно добавить в заказ.
- **Галерея** — просмотр фото на весь экран, стрелки/свайп, Esc.
- **Бронь столика** — время только в часы работы (прошедшее время сегодня недоступно), маска телефона, счётчик гостей; после отправки показывается «билет» брони. **Форма пока никуда не отправляет данные** — для реальной работы её нужно подключить (Telegram-бот, e-mail или сервис форм).
- Статус «Сейчас открыто / закрыто» по киевскому времени, 3D-наклон карточек, счётчики, индикатор прокрутки, подсветка текущего раздела в навигации.

## Что можно менять под себя

- Меню и цены — блоки `.menu-item` в `index.html` (секции с `id="tab-coffee"`, `tab-breakfast`, `tab-dessert`, `tab-drinks`).
- Телефон, адрес, часы — в шапке, герое, секции контактов и подвале (`tel:`-ссылки и текст).
- Фотографии — ссылки `images.unsplash.com` в `index.html` и `css/style.css`; замените на свои.
- Карта — iframe OpenStreetMap в секции контактов; координаты маркера можно поменять в URL (`marker=ШИРОТА,ДОЛГОТА`).
- Шрифты — подключение Google Fonts в `<head>` `index.html`.

Зависимостей и сборки нет: три файла, работают без интернета частично (карта, шрифты и фото подгружаются онлайн).
